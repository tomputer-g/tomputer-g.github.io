# Folly

Hello!

| | |
|---|---|
| **Device** | Standard Open SO-101 Follower Arm |
| **Codebase** | https://github.com/tomputer-g/so101 |
| **Built** | May 2026 |
| **Material** | Bambu PLA, default infill, 0.6mm nozzle |
| **DoF** | 6 |
| **Port** | `/dev/ttyACM0` (may change?) |

Note: This SO-101 is built with FeeTech 12V motors (30 kg-cm stall torque) each, instead of the 7.4V default (16.5 kg-cm). This version requires a 12V 5A+ power supply.

Folly is a small robotic arm built with 3D-printed parts and FeeTech servo motors. Due to the design, it can be clamped to any table surface with just a DC jack and a USB cable for control.
